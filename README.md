# Where in the World (v2)

A browser game: guess where a patch of satellite imagery is on the map.
Work in progress; see [docs/PROTOTYPE_PLAN.md](docs/PROTOTYPE_PLAN.md).

Rebuild of [where-in-the-world](https://github.com/hurr-son/where-in-the-world).

## Development

```bash
npm install
cp .env.example .env   # add your Mapbox token
npm run dev
```
